# 🔧 Underhållsschema för NexusTrack

## Efter varje körning
* Kontrollera att kamerans lins på OnePlus 8T är ren.
* Rensa banden från gräs, snö eller smuts.

## Veckovis underhåll
* **Bultförband:** Kontrollera att alla M3-skruvar i 3D-plattan sitter fast.
* **Kablage:** Se efter tecken på nötning på jumper-kablar och USB-C-anslutningar.
* **Kalibrering:** Testa ultraljudssensorernas precision mot ett fast hinder.

## Månadsvis underhåll
* **Batterihälsa:** Kontrollera powerbankens kapacitet och laddningscykler.
* **Mjukvaruuppdatering:** Kör `pkg upgrade` i Termux för att säkerställa senaste säkerhetspatchar.
