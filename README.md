# 🚜 NexusTrack - Modular Autonomous Robot
![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)

NexusTrack är en öppen, modulär plattform för trädgårdsrobotik. Genom att använda en smartphone som hjärna och en kraftfull bandvagn som bas, skapar vi en maskin som klarar allt från gräsklippning till snöskottning.

## 🧠 Systemarkitektur
- **Hjärna:** OnePlus 8T (Python/Termux)
- **MCU:** Elegoo Mega 2560 (Low-level control)
- **Kommunikation:** MQTT över Proxmox/Mosquitto
